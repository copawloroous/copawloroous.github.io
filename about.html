Publications

Research Papers

Published · IEEE TGRS 2025 · First Author

Self-Supervised Graph Masked Autoencoders for Hyperspectral Image Classification

Venue: IEEE Transactions on Geoscience and Remote Sensing，CAS Q1 TOP, CCF-B, IF 9.4.

Bibliography: TGRS (2025), Volume 63: 5509918. DOI: 10.1109/TGRS.2025.3555967. Published on 2025.03.28.

Summary: This work proposes a self-supervised graph masked autoencoder for hyperspectral image classification. It learns self-supervised features, uses graph convolutional encoding for multi-scale receptive-field information, and designs a cross-correlation decoder to fuse multi-scale features, improving the accuracy of downstream supervised classification networks.

Published · IEEE TIP 2026 · Second Author, Advisor First Author

Spectral State Fusion Tree Mamba for Hyperspectral Image Classification

Venue: IEEE Transactions on Image Processing，CAS Q1 TOP, CCF-A, IF 15.3.

Bibliography: TIP (2026), Volume 35: 42275320. DOI: 10.1109/TIP.2026.3700929. Published on 2026.06.11.

Summary: This work proposes a spectral-state fusion tree Mamba algorithm for hyperspectral image classification. It constructs reasonable spatial relationships through spatial and spectral tree scanning, introduces a spectral-state fusion mechanism, and enables spectral feature extraction in the Mamba state domain, enhancing multi-scale spectral relationships and classification performance.

Under Review · IEEE TPAMI · Second Author, Advisor First Author

PriorFusion: Semantic Structural Prior Attention for Image Fusion

Target Venue: IEEE Transactions on Pattern Analysis and Machine Intelligence，CAS Q1 TOP, CCF-A, IF 20.4.

Summary: This work proposes a unified image fusion framework named PriorFusion. By enforcing semantic structural consistency in attention affinity matrices, it bypasses feature-space conflicts between vision foundation models and fusion backbones. With fully frozen VFM priors, including SCPA and SSGM modules, it achieves state-of-the-art performance on six fusion tasks and downstream detection and segmentation.

Multimodal Controllable Generation Model for Image Fusion

Target Venue: AAAI Conference on Artificial Intelligence, CCF-A.

Summary: This project studies a generation-prior image fusion paradigm. Original inputs are used as image conditions to preserve fidelity, while sample-wise text prompts control quality enhancement. The goal is to move beyond blindly maximizing input fidelity metrics and achieve a controllable visual-quality trade-off between degraded fidelity and high-quality fidelity.
