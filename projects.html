PriorFusion
IEEE TPAMI · Second Author, Advisor First Author · Under Review

PriorFusion: Semantic Structural Prior Attention for Image Fusion

PriorFusion is a unified image fusion framework designed to avoid the feature-space conflict between frozen vision foundation models and fusion backbones. It uses semantic structural consistency in attention affinity matrices and frozen VFM priors, including SCPA and SSGM modules.

  • Target Venue: IEEE Transactions on Pattern Analysis and Machine Intelligence, CAS Q1 TOP, CCF-A, IF 20.4.
  • Tasks: six image-fusion tasks plus downstream detection and segmentation.
  • Status: Under review.

GenFusion
AAAI · First Author · In Progress

Multimodal Controllable Generation Model for Image Fusion

This project studies image fusion with generation priors: source images provide fidelity-preserving conditions, while per-sample text prompts guide visual quality enhancement and enable controllable fusion quality trade-offs.

  • Target Venue: AAAI Conference on Artificial Intelligence, CCF-A.
  • Core Idea: move from metric-driven fidelity toward controllable high-quality fidelity.
  • Status: Ongoing research.
